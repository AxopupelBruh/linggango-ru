# Linggango — русский перевод сборки

Полный перевод модпака **Linggango** на русский: интерфейс модов, подсказки
предметов, квесты FTB Quests, книги Patchouli и книги в данжах.

| | |
|---|---|
| Сборка | **Linggango V6.6.6cf** |
| Minecraft | 1.20.1 |
| Forge | 47.4.20 |
| Модов | 430 |
| CurseForge | <https://www.curseforge.com/minecraft/modpacks/linggango> |

> **Перевод сделан ИИ-агентом.** Дальше вычитан и проверен в игре.
> Промты, скрипты и словари лежат здесь же — перевод можно повторить
> или переделать под другую сборку.

## Установка

**Ресурспак сообщества больше не нужен.** Раньше перевод опирался на пак
`MPLOCmods` — его переводы забирались в наш ресурспак, а сам пак убирался
из списка. Теперь наш пак самодостаточный: всё, что было видно в игре
с `MPLOCmods`, лежит внутри `zz_linggango_ru.zip`.

### Шаг 1. Скачай архив

Релиз: <https://github.com/AxopupelBruh/linggango-ru/releases/latest>

* **`linggango-ru-v6.6.6.zip`** — всё для установки, распаковывается прямо в папку сборки;
* **`zz_linggango_ru.zip`** — только ресурспак, если ставишь по частям.

### Шаг 2. Распакуй в папку сборки

Найди папку инстанса. В CurseForge-клиенте: `CurseForge → Instances → Linggango
→ папка с `.minecraft` внутри`. В других лаунчерах — папка, где лежат `mods`,
`config`, `resourcepacks`.

Распакуй архив **в корень этой папки** — рядом с `mods`, `config` и
`resourcepacks`. Получится:

```
<папка сборки>/
├── resourcepacks/zz_linggango_ru.zip
├── kubejs/client_scripts/ru_tooltip_translator.js
├── kubejs/client_scripts/ars-nouveau-ponders.js
├── kubejs/client_scripts/tooltip_additions.js
├── kubejs/server_scripts/ru_measure_of_stone.js
├── mods/zz_linggango_ru_books.jar
├── datapacks/zz_linggango_ru_books/
└── config/ftbquests/quests/          ← 186 переведённых .snbt
```

Или одной командой:

```bash
unzip linggango-ru-v6.6.6.zip -d "/путь/к/папке/сборки"
```

> **Перед копированием сохрани свою папку квестов** (`config/ftbquests/quests/`) —
> она понадобится, если сборка обновится (см. «Обновление сборки»).

### Шаг 3. Проверь порядок ресурспаков

Наш пак должен быть **последним** в списке. В Minecraft lang-файл пака
**заменяет** файл мода целиком, а не дополняет его — пак, стоящий выше,
затрёт наш, и весь перевод пропадёт.

В `options.txt` должно быть:

```
lang:ru_ru
resourcePacks:[...,file/zz_linggango_ru.zip]
```

Если ставил через CurseForge, порядок прописал сам клиент — проверь только
что наш пак последний. В настройках сборки это
`config/linggango-resourcepacks.toml`.

#### Проверка

В игре: **Options → Language → Русский**. В `options.txt` должно быть
`lang:ru_ru`. Открой любой мод — интерфейс должен быть на русском.

## Что нового в этой версии

Полностью пофикшенный перевод — исправлено то, из-за чего английский
возвращался в игру, хотя переводы формально были.

- **Убрана зависимость от чужого ресурспака.** Переводы `MPLOCmods`
  (24 245 ключей по 140 неймспейсам) перенесены внутрь нашего пака вместе
  с переведёнными книгами. Пак `MPLOCmods` больше не нужно ставить —
  и больше нечего обновлять отдельно.
- **Починены 3 952 ключа, которые были переведены, но не показывались.**
  Причина: lang-файл ресурспака заменяет файл мода целиком. Наш файл
  затирал чужие переводы, ключ пропадал — и игра откатывалась на `en_us`.
  Теперь наш файл содержит объединение всех источников.
- **Возвращены 409 ключей** описаний зачарований (`enchdesc`), 102 страницы
  PonderJS и 10 названий биомов — их перевод лежит в паке KubeJS, и наш
  пак их тоже затирал.
- **Возвращён перевод мода `collective`** (757 ключей) — он лежит в паке
  `serilum`, а не в самом моде.
- **Починены 999 строк**, где чужой `ru_ru.json` в jar отстал от `en_us`:
  тултипы показывали старые числа (`+0.1` вместо `+0.2`).
- Убраны **97 обрывов текста** и разнобой «ты/вы» — теперь везде «вы».
- Из книг убраны **322 «переведённых ключа»**: Patchouli сам подставляет
  перевод по ключу, а переведённый ключ игра не находила и показывала текстом.
- **54 точечные правки** по ключу: §-коды, гомоглифы, склейки слов, бренды.
- Добавлен перевод сцен **Ars Nouveau** и книги **«Measure of Stone»** —
  их текст захардкожен в `.class` и ресурспаком не достаётся.

### Что осталось на английском

Честный список — что переводом не берётся и почему:

- **Экран выбора кольца и меню настроек мода `linggango_tweaks`** —
  1 789 строк вшиты в код мода (`Component.literal`). Ресурспак их не
  трогает. Тултипы предметов из этого мода переведены (125 из 127),
  а меню и конфиги требуют патча мода.
- **GUI-экраны с текстом в коде** у других модов — правятся только внутри модов.
- **Строки в JSON-конфигах** (не в `lang/`) — их перевод ломает конфиги.
- **Имена редкости Brutality** — у мода свой шрифт без кириллицы, русский
  текст превратился бы в квадратики.
- **Картинки с текстом** — это логотипы модов, то есть бренды. Слой картинок
  не тронут вообще.
- **Технические строки**: URL, id, значения конфигов, ники авторов, названия
  треков — их не переводят по определению.

Полный разбор — [`docs/ЧТО_ПЕРЕВЕДЕНО.md`](docs/ЧТО_ПЕРЕВЕДЕНО.md).

## Обновление сборки

Перевод живёт в ресурспаке, KubeJS и квестах — **jar-файлы модов не патчатся**.
Поэтому обновление через CurseForge ничего не ломает: перезаписывать нечего.

### Что устоит

- **Переводы модов.** После обновления мода наш `ru_ru.json` продолжит
  перекрывать его lang-файл.
- **Подсказки.** Скрипт ищет точное совпадение строки. Если мод переписал
  фразу — подсказка просто останется английской, игра не сломается.
- **Сохранения, сервер, моды.** Мы не меняем ничего, кроме пака, скрипта
  и квестов.

### Что может сломаться

1. **Квесты при смене ключа шифрования.** Файлы зашифрованы ключом из констант
   мода `linggango_tweaks`. Если автор их поменяет, FTB Quests покажет пустые
   квесты.
   *Лечится так:* перед обновлением скопируй `config/ftbquests/quests/` в сторону.
   Сломалось — верни старую папку и перешифруй заново (`tools/lgq_crypt.py`).
   Крайний вариант — удалить переведённые `.snbt`: FTB Quests восстановит
   оригинальные квесты, но на английском.

2. **Книги в данжах.** Датапак **заменяет** лут-таблицу целиком. Если мод
   обновится и изменит её содержимое, наш датапак перекроет новое.
   *Лечится так:* пересобрать датапак
   (`python3 tools/fix_books.py extract && python3 tools/fix_books.py build`).
   Пока не пересобрано — **удали `zz_linggango_ru_books.jar`**, так безопаснее.

3. **Новые строки.** Мод добавил текст — он останется английским, пока его
   не переведут. Лечится повторным прогоном `tools/`.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Всё на английском | наш пак не последний в списке ресурспаков |
| Английский только в подсказках предметов | не установлен `ru_tooltip_translator.js` |
| Квесты пустые | сменился ключ шифрования — см. выше |
| Русский интерфейс, но английские названия предметов | наш пак не последний в списке |
| Квадратики вместо букв | мод рисует текст своим шрифтом без кириллицы |

## Как дописать перевод

Всё в `tools/` — рабочий конвейер, а не разовые скрипты.

```bash
cd tools/

# 1. что осталось на английском
python3 collect.py
python3 fill_lang_gap.py              # → work/lang_need.json

# 2. перевести (ключ DeepSeek в tools/.deepseek_key)
python3 run.py --source mods --out mods_ru

# 3. собрать релиз
python3 build_resourcepack.py         # → resourcepacks/zz_linggango_ru.zip
python3 fix_books.py build            # → датапак с книгами
python3 build_tooltip_script.py       # → kubejs/client_scripts/…
python3 publish_release.py --push     # → собрать и залить репозиторий
```

Проверка перед выкладкой:

```bash
python3 tools/verify_all.py           # → «ВСЁ ОК»
python3 tools/audit_font_coverage.py  # символы без глифа в шрифте игры
```

Ключи API лежат в `tools/.deepl_key*`, `.deepseek_key*`, `.gemini_key`
и в репозиторий не попадают — сборщик релиза их вырезает.

## Правила, по которым переводили

- Бренды — латиницей: FTB, JEI, REI, Create, Mekanism, Ars Nouveau, Curios,
  Patchouli, Sophisticated Storage, Xaero's и другие.
- `§`-коды, плейсхолдеры (`%s`, `%d`, `$(item)`), теги и id не отдаются
  переводчику: их заменяют токенами и возвращают на место.
- Чужой корректный перевод мода не переопределяется нашим.
- Ванильный `ru_ru` 1.20.1 (8 799 ключей) встроен в пак — иначе пак с парой
  ключей откатил бы весь интерфейс игры на английский.
- Один и тот же термин переводится одинаково во всей сборке.
