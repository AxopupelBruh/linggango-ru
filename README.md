# Linggango — русский перевод сборки

Полный перевод модпака **Linggango** на русский: интерфейс модов, подсказки
предметов, квесты FTB Quests, книги Patchouli и книги в данжах.

| | |
|---|---|
| Сборка | **Linggango V6.6.6cf** |
| Minecraft | 1.20.1 |
| Forge | 47.4.20 |
| Модов | 430 |
| CurseForge | <https://www.curseforge.com/minecraft/modpacks/linggango> |

> **Перевод сделан ИИ-агентом.** Дальше вычитан и проверен в игре.

---

## Установка

Ресурспак сообщества больше не нужен: его переводы перенесены внутрь нашего,
пак самодостаточный.

**1. Скачай архив** — <https://github.com/AxopupelBruh/linggango-ru/releases/latest>

* `linggango-ru-v6.6.6.zip` — всё для установки;
* `zz_linggango_ru.zip` — только ресурспак, если ставишь по частям.

**2. Распакуй в папку сборки** — ту, где лежат `mods`, `config`, `resourcepacks`:

```bash
unzip linggango-ru-v6.6.6.zip -d "/путь/к/папке/сборки"
```

**3. Проверь два пункта**

| Что | Где |
|---|---|
| `lang:ru_ru` | `options.txt` |
| `file/zz_linggango_ru.zip` — **последний** в списке ресурспаков | `options.txt`, `config/linggango-resourcepacks.toml` |

Порядок важен: lang-файл пака **заменяет** файл мода целиком, а не дополняет
его. Пак, стоящий выше, затрёт наш — и перевод пропадёт.

Подробности и разбор проблем — в [`docs/УСТАНОВКА.md`](docs/УСТАНОВКА.md).

### Что нового в этой версии

- **Убрана зависимость от чужого ресурспака** — его переводы (24 245 ключей)
  и переведённые книги теперь внутри нашего пака.
- **Починено 3 952 ключа, которые были переведены, но не показывались.** Наш
  lang-файл затирал чужие переводы, ключ пропадал — и игра откатывалась на
  английский.
- **Возвращены переводы** описаний зачарований, сцен PonderJS и мода `collective`.
- **Починены** 999 устаревших строк, 97 обрывов текста, 322 битых ключа в книгах.
- **Добавлены** переводы сцен Ars Nouveau и книги «Measure of Stone».

Что осталось на английском и почему — в
[`docs/ЧТО_ПЕРЕВЕДЕНО.md`](docs/ЧТО_ПЕРЕВЕДЕНО.md).

## Если сборка обновится

Перевод живёт в ресурспаке, KubeJS и квестах — jar-файлы модов не патчатся,
поэтому обновление через CurseForge ничего не ломает. Сломаться может только
смена ключа шифрования квестов: сохрани `config/ftbquests/quests/` перед
обновлением. Подробности — в
[`docs/ЧТО_ПЕРЕВЕДЕНО.md`](docs/ЧТО_ПЕРЕВЕДЕНО.md).

## Структура репозитория

```
install/                    ← копируется в корень инстанса сборки
├── resourcepacks/zz_linggango_ru.zip
├── kubejs/                ← переводчик подсказок и правки
├── mods/zz_linggango_ru_books.jar        ← необязательный
├── datapacks/zz_linggango_ru_books/
└── config/ftbquests/quests/              ← 186 переведённых .snbt

data/      ← словари «английский → русский»
docs/      ← установка и отчёты
tools/     ← скрипты, которыми сделан перевод
```
