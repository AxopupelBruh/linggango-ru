# Linggango — полный перевод на русский

Полный перевод модпака **LIngango** на русский язык. Переведены все текстовые
слои, которые вообще можно перевести: интерфейс модов, подсказки предметов,
квесты FTB Quests, книги Patchouli и книги в данжах.

| | |
|---|---|
| Сборка | **LIngango V6.6.6hf** |
| Minecraft | 1.20.1 |
| Forge | 47.4.20 |
| Модов в сборке | 430 (285 неймспейсов с переводом) |
| Сборка на CurseForge | <https://www.curseforge.com/minecraft/modpacks/linggango> |
| Язык перевода | `ru_ru` (русский) |

## Что переведено

| Слой | Что именно | Объём |
|---|---|---|
| **Ресурспак** `zz_linggango_ru.zip` | lang-файлы всех модов (названия предметов, блоков, существ, зачарований, конфигов), страницы книг Patchouli, официальный ванильный `ru_ru` 1.20.1 | 2 202 файла, 285 lang-файлов, ~101 тыс. ключей, из них 46 160 — наши переводы |
| **KubeJS-скрипт** `ru_tooltip_translator.js` | подсказки предметов, которых нет в lang-файлах (строки, зашитые в Java-код модов: «Урон: 10», «Требует уровень», формулы характеристик) | 8 916 строк |
| **Квесты FTB Quests** | заголовки, описания, подзаголовки, подсказки и «плавающие» тексты квестов | 186 файлов, 23 952 квеста, 5 527 заголовков |
| **Книги в данжах** `zz_linggango_ru_books.jar` | страницы книг, которые лежат прямо в лут-таблицах и не берутся ни из lang-файлов, ни из Patchouli | 38 страниц в 2 лут-таблицах |
| **Словари** `data/` | исходные таблицы «английский → русский» для всех слоёв | 76 354 записи |

Названия актов приведены к единому виду: **Акт 0 … Акт XI** (`Акт II: Повелитель гоблинов`).

### Что сознательно НЕ переведено

- **Объёмный 3D-текст на картинках** (логотипы модов, ~99 % картинок сборки) — это бренды.
  Плоский 2D-текст тоже оставлен как есть: слой картинок заморожен, оригиналы
  `kubejs/assets/customtextures/textures/` не изменены (проверено по md5).
- **GUI-экраны с зашитым в код текстом** — решение автора сборки, такие строки
  не проходят через lang-файлы и правятся только в самих модах.
- **Строки в JSON-конфигах модов** (не в `lang/`) — их перевод ломает конфиги.
- **Иероглифы и эмодзи в оригинальных английских строках** — оставлены как у авторов
  модов (например `Игрушка §a東漢 駒§r` у goety — это собственный русский перевод мода).

## Установка

### Шаг 1. Базовый ресурспак MPLOCmods — обязательно

Наш перевод **добивает** уже существующие переводы, а не заменяет их. Фундамент —
массовая локализация от сообщества:

**<https://www.curseforge.com/minecraft/texture-packs/mplocmods>** —
скачать последнюю версию (v44, 2 327 неймспейсов с `lang/ru_ru.json`).

> **Последняя версия всегда на CurseForge.** В этом репозитории лежит копия для
> офлайн-установки, но она может отставать. Ставить лучше с CurseForge —
> так вы получите свежие переводы от сообщества, а наш пак перекроет только то,
> что ещё не переведено.

Как поставить: скачать `.zip` → `LIngango/.minecraft/resourcepacks/` (в CurseForge
клиенте: «Install» → «В папку сборки»). Дальше — Шаг 2.

### Шаг 2. Наш ресурспак — обязательно

Скачать `install/resourcepacks/zz_linggango_ru.zip` из этого репозитория
(или взять из `resourcepacks/` в установленной сборке) и положить в
`LIngango/.minecraft/resourcepacks/`.

**Порядок паков в списке — важен.** Наш пак должен быть **последним**:

```
Версии: 1.20.1
Ресурспаков: ...,file/MPLOCmods.zip,file/zz_linggango_ru.zip
```

Причина: в Minecraft lang-файл ресурспака **заменяет** файл мода целиком, а не
мержится с ним. Если поставить наш пак раньше — `MPLOCmods` его перекроет.
Если `MPLOCmods` поставить позже — он перекроет наш ванильный `ru_ru` и 285 неймспейсов.

В CurseForge-сборке это делается автоматически в `options.txt` и
`config/linggango-resourcepacks.toml` — там наш пак уже стоит последним.

### Шаг 3. Скрипт подсказок — обязательно

`install/kubejs/client_scripts/ru_tooltip_translator.js` →
`LIngango/.minecraft/kubejs/client_scripts/ru_tooltip_translator.js`.

Скрипт подхватывает подсказки предметов, которых нет в lang-файлах. Без него
в игре останутся английские строки внутри подсказок (формулы урона, требования,
эффекты).

### Шаг 4. Переведённые квесты — обязательно

`install/config/ftbquests/quests/` → `LIngango/.minecraft/config/ftbquests/quests/`.

186 файлов `.snbt`. **Перед копированием сделайте копию своей папки квестов** —
см. раздел про обновление сборки.

### Шаг 5. Книги в данжах — по желанию

`install/mods/zz_linggango_ru_books.jar` → `LIngango/.minecraft/mods/`.

**Этот мод не обязателен.** Он не добавляет геймплея и не нужен, чтобы перевод
работал. Это перекрытие лут-таблиц датапаком: в сундуках данжей лежат книги,
страницы которых зашиты прямо в JSON лут-таблицы — ни ресурспак, ни KubeJS их
не трогают. Мод заменяет эти лут-таблицы на русские.

Без него всё остальное переведено, а эти 38 страниц книг останутся на английском.

### Шаг 6. Язык игры

В `options.txt` должно быть `lang:ru_ru`.

## Устойчивость к обновлению сборки

Перевод **сделан через ресурспак, датапак и KubeJS — jar-файлы модов не патчатся**
(это главное правило: патченные jar слетают при каждом обновлении через CurseForge).
Поэтому переживает обновление лучше, чем «зашитый» в мод перевод.

### Что НЕ сломается

- **Переводы модов (ресурспак).** Моды не изменены. После обновления мода его
  `en_us` может измениться, но наш `ru_ru.json` продолжит перекрывать его
  lang-файл — перевод останется на месте.
- **Подсказки (KubeJS).** Скрипт сопоставляет английскую строку по точному
  совпадению. Если мод изменит формулировку — подсказка просто останется
  английской, но ничего не сломается.
- **Сервер, сохранения, моды.** Ничего в игровых файлах не меняется, кроме
  ресурспака, скрипта, квестов и (опционально) книг.

### Что МОЖЕТ сломаться

1. **Квесты при смене ключа шифрования.** Файлы квестов зашифрованы `LGQ1:`
   ключом, который выводится из констант мода `linggango_tweaks`. Если автор
   обновит этот мод и изменит константы — файлы перестанут расшифровываться, и
   FTB Quests покажет пустые или сломанные квесты.
   *Что делать:* **перед обновлением сборки** скопируйте
   `config/ftbquests/quests/` в сторону. Если после обновления квесты сломались —
   верните старую папку, а новую перешифруйте заново (в `tools/` есть `lgq_crypt.py`).
   Как крайний вариант — удалить переведённые `.snbt`: FTB Quests восстановит
   оригинальные квесты из ресурса мода, но они будут на английском.

2. **Датапак книг при обновлении мода.** Датапак **заменяет** лут-таблицу целиком.
   Если мод, чьи книги мы перевели, обновится и изменит содержимое своей лут-таблицы —
   наш датапак (у него приоритет выше) перекроет её, и новое содержимое пропадёт.
   *Что делать:* после обновления `ati_structures` пересобрать датапак
   (`python3 tools/fix_books.py extract && python3 tools/fix_books.py build`).
   Пока не пересобрали — **удалите `zz_linggango_ru_books.jar`**, это безопаснее,
   чем отдать игрокам устаревшую лут-таблицу.

3. **Новые ключи у обновлённых модов.** Если мод добавил новые строки, а мы их
   ещё не перевели — эти конкретные строки останутся английскими. Лечится
   повторным прогоном перевода (`tools/`).

### Что не переведётся никогда (в этой версии)

- Текст, зашитый в GUI-код модов (кнопки, заголовки экранов, названия вкладок).
- Картинки с текстом.
- Строки в конфигах модов (не в `lang/`).
- Названия, которые мод берёт из имени файла или из ID ресурса.

## Структура репозитория

```
install/                       ← копируется в корень инстанса сборки
├── resourcepacks/zz_linggango_ru.zip
├── kubejs/client_scripts/ru_tooltip_translator.js
├── mods/zz_linggango_ru_books.jar          ← необязательный мод с книгами
├── datapacks/zz_linggango_ru_books/
└── config/ftbquests/quests/                ← 186 переведённых .snbt
data/                          ← итоговые словари «английский → русский»
docs/                          ← гайд по локализации и план перевода
│   ├── LOCALIZATION_GUIDE.md      — как устроен перевод, все правила и параметры
│   └── TRANSLATION_PLAN.md        — план и журнал работ по сборке
tools/                         ← скрипты, которыми сделан перевод
```

## Как дописать перевод

Всё в `tools/` — рабочий конвейер, а не разовые скрипты.

```bash
cd tools/

# 1. собрать, что осталось на английском
python3 collect.py
python3 fill_lang_gap.py            # → work/lang_need.json

# 2. перевести (нужен ключ DeepSeek в tools/.deepseek_key)
python3 run.py --source mods --out mods_ru

# 3. собрать релиз
python3 build_resourcepack.py       # → resourcepacks/zz_linggango_ru.zip
python3 fix_books.py build          # → датапак с книгами
python3 build_tooltip_script.py     # → kubejs/client_scripts/…
python3 publish_release.py --push   # → собрать и залить репозиторий
```

Проверка перед выкладкой:

```bash
python3 tools/verify_all.py         # → «ВСЁ ОК»
python3 tools/audit_font_coverage.py  # символы без глифа в шрифте игры
```

Ключи API лежат в `tools/.deepl_key*`, `.deepseek_key*`, `.gemini_key` и
**никогда не попадают в репозиторий** — они исключены сборщиком релиза.

## Правила перевода, которые соблюдались

- Бренды остаются латиницей: FTB, JEI, REI, Create, Mekanism, Ars Nouveau, Curios,
  Patchouli, Sophisticated Storage, Xaero's и т. д.
- `§`-коды, плейсхолдеры (`%s`, `%d`, `$(item)`), теги и ID не отдаются переводчику:
  они маскируются токенами и возвращаются на место.
- Чужие (общинные) переводы модов не переопределяются нашими, если мод уже даёт
  корректный русский.
- Ванильный `ru_ru` 1.20.1 (8 799 ключей) встроен в ресурспак — иначе пак с
  парой ключей откатил бы весь интерфейс игры на английский.
