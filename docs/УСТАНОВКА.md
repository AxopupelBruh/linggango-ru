# Установка русского перевода Linggango

Сборка **Linggango V6.6.6cf** (Minecraft 1.20.1 / Forge).

## Что нужно

Ресурспак сообщества (`MPLOCmods`) **больше не нужен** — его переводы перенесены
внутрь нашего пака. Ставится один архив, без внешних зависимостей.

## Способ 1. Автоматически

```bash
unzip linggango-ru-v6.6.6.zip -d /tmp/linggango-ru
/tmp/linggango-ru/linggango-ru/install.sh "/путь/к/папке/сборки"
```

Скрипт сам скопирует файлы и **сохранит твои текущие квесты** в
`config/ftbquests/quests.backup.<дата>` — пригодится, если сборка обновится.

## Способ 2. Вручную

Найди папку инстанса: та, где лежат `mods`, `config`, `resourcepacks`.
В CurseForge-клиенте: `CurseForge → Instances → Linggango → папка с .minecraft`.

Скопируй из архива папку `install/` **в корень папки сборки**. Получится:

```
<папка сборки>/
├── resourcepacks/zz_linggango_ru.zip
├── kubejs/client_scripts/ru_tooltip_translator.js
├── kubejs/client_scripts/ars-nouveau-ponders.js
├── kubejs/client_scripts/tooltip_additions.js
├── kubejs/server_scripts/ru_measure_of_stone.js
├── mods/zz_linggango_ru_books.jar
├── datapacks/zz_linggango_ru_books/
└── config/ftbquests/quests/          ← 186 переведённых .snbt
```

## Проверка

1. В `options.txt` должно быть `lang:ru_ru`.
2. В списке ресурспаков `file/zz_linggango_ru.zip` должен быть **последним**.

   Это обязательно: lang-файл ресурспака **заменяет** файл мода целиком,
   а не дополняет его. Если наш пак окажется не последним, его перекроет
   другой пак — и перевод пропадёт.

3. В игре: **Options → Language → Русский**. Открой любой мод —
   интерфейс должен быть на русском.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| Всё на английском | наш пак не последний в списке ресурспаков |
| Английский только в подсказках предметов | не установлен `ru_tooltip_translator.js` |
| Квесты пустые | сменился ключ шифрования — верни папку из бэкапа |
| Квадратики вместо букв | мод рисует текст своим шрифтом без кириллицы |

Подробности — в [README репозитория](https://github.com/AxopupelBruh/linggango-ru).
