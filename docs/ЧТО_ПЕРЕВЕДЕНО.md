Сводка по переводу сборки **Linggango V6.6.6cf** (Minecraft 1.20.1 / Forge, 430 модов).

## Почему перевод иногда не появлялся

Главная ловушка Minecraft: **lang-файл ресурспака заменяет файл мода целиком,
а не дополняет его.**

Наш пак идёт последним в списке (высший приоритет) и пишет lang-файлы по 300
неймспейсам. Значит, каждый такой файл обязан содержать **всё**, что было видно
в игре до него: переводы модов, переводы пака KubeJS, переводы пака `serilum`
и переводы чужой локализации `MPLOCmods`. Забытый ключ = английский в игре.

Что из-за этого чинилось в этой версии:

| Что | Было | Стало |
|---|---|---|
| ключей из `MPLOCmods`, затёртых нашим паком | 3 492 | 0 |
| ключей из `en_us` модов, отсутствующих у нас | 313 | 222 (из них 196 — с пустым английским, не видны) |
| ключей описаний зачарований (`enchdesc`) из пака KubeJS | потеряно 295 | 0 |
| ключей PonderJS из пака KubeJS | потеряно 102 | 0 |
| перевод мода `collective` из пака `serilum` | потеряно 14 | 0 |

Итог: **3 952 ключа перешли с английского на русский, регрессий
(русский → английский) — ноль.** Проверка моделирует игру с паком и без него:
состояние идентично — 111 842 ключа, 108 644 русских.

**Чужой локализационный пак больше не нужен.** Его переводы (24 245 ключей
по 140 неймспейсам) и переведённые книги перенесены внутрь нашего пака.
Модов, которых нет в сборке, мы не трогаем — их переводы в пак не попадают.

«прочее», «сообщения команд», «миксины».

## Технические решения

- **Ванильный `ru_ru` встроен в пак.** Файл `assets/minecraft/lang/ru_ru.json`
  из ресурспака заменяет ванильный целиком: приложи две строки — весь
  интерфейс игры уйдёт на английский. В паке лежит официальный русский
  1.20.1 (8 799 ключей) плюс наши правки.
- **`assets/minecraft/font/default.json`** — файл шрифта в стеке ресурспаков
  один на всех, побеждает тот, что выше в списке. Сборщик собирает в него
  bitmap-провайдеры всех модов и включённых паков (28 листов) — иначе
  иконки brutality, simplyswords и bbb превращаются в квадраты.
- **`assets/linggango_tweaks/texts/*.txt`** — подсказки и строки экрана
  загрузки. Мод читает их через `ResourceManager`, поэтому пак подкладывает
  свои файлы (17 подсказок + 131 строка).
- **Квесты зашифрованы** ключом из констант мода `linggango_tweaks` (формат
  `LGQ1:`). Правка идёт через `tools/lgq_crypt.py` — шифрование сохраняется,
  FTB Quests читает файлы как обычно.
- **Книги в данжах** — датапак перекрывает две лут-таблицы. Датапак заменяет
  таблицу целиком: если мод изменит её, наша версия перекроет новое.

## Правила перевода

- Бренды — латиницей: FTB, JEI, REI, Create, Mekanism, Ars Nouveau, Curios,
  Patchouli, Sophisticated Storage, Xaero's и другие.
- `§`-коды, плейсхолдеры (`%s`, `%d`, `$(item)`), теги и id не отдаются
  переводчику: их заменяют токенами и возвращают на место.
- Чужой корректный перевод мода не переопределяется нашим. Перекрываем только
  пустые и английские значения, а также переводы с разъехавшимися
  `%`-аргументами.
- Один и тот же термин переводится одинаково во всей сборке — глоссарий
  в `data/terms_merged.json`.
